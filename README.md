# 🍝 Bella Vita Italian Restaurant – Reservation Management System  

🎯 **A complete web solution to streamline reservations, menu management, and customer engagement**  

---

## 📌 Project Overview  

The **Bella Vita Reservation Management System** is a full-stack web application designed to optimize restaurant operations. It empowers **admins**, **staff**, and **customers** with seamless tools for managing reservations, menus, tables, queries, and loyalty rewards — all through an intuitive and secure interface.

Built with modern web technologies, the system is ideal for enhancing customer service and internal efficiency.

---

## ⚙️ Technical Stack  
- **Frontend**: HTML, CSS, JavaScript  
- **Backend**: PHP
- **Database**: MySQL
- **Tools**: Visual Studio Code, WAMP Server, phpMyAdmin

---

## ✨ Key Features  

### 👑 Admin Panel  
- **Secure Admin Registration & Login**
- **Admin Dashboard**: Central hub for managing system-wide operations  
- **User Management**: Add, edit, or delete customers and staff  
- **Menu Management**: Update dishes, prices, and availability  
- **Reservation Management**: View, edit, or cancel bookings  
- **Table Management**: Adjust table availability  
- **Customer Queries**: Respond to Contact Us submissions  

### 👨‍🍳 Staff Panel  
- **Secure Staff Registration & Login**  
- **Staff Dashboard**  
- **Manage Reservations**: View, update, and cancel bookings  
- **Manage Tables**: Adjust table statuses in real-time  
- **Customer Queries**: Respond to inquiries from the Contact Us form  

### 🍽️ Customer Features  
- **Menu Browsing**: Explore dishes with images and details  
- **Secure Registration & Login**  
- **Book a Reservation**: Choose date, time, guests, and preferences  
- **Loyalty Rewards**  
  - Earn 10 points per reservation  
  - 200+ points: Free drink  
  - Every 10th reservation: Free  
- **Read Reviews**  
- **Contact Us Form**: Submit queries easily  
- **Customer Dashboard**  
  - Manage reservations  
  - Edit profile  
  - Track queries & responses
